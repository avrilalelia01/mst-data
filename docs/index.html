MST Shopee Sales Analyzer

An in-house seller analytics platform that transforms Shopee order data into actionable business insights.

🔒 In-House Seller Tool

About

MST Shopee Sales Analyzer is a private, in-house business intelligence tool built for Shopee sellers to analyze their own store performance. It connects to the Shopee Open Platform API to securely collect order and product data, compute key performance indicators, generate prioritized business recommendations, and export Power BI-ready reports — all running locally on the seller's own machine.

Key Features

📊

KPI Dashboard

Computes total revenue, order count, average order value, gross profit margin, return rate, and week-over-week / month-over-month trends.

🛍️

Product Analytics

Per-product revenue contribution, units sold, profit margin, and conversion rate analysis across all active listings.

💡

Smart Recommendations

Automatically generates HIGH/MEDIUM/LOW priority recommendations for pricing, inventory, listings, and promotions.

📁

Power BI Export

Exports star-schema CSV files (Sales Fact, Product Dim, Date Dim, Recommendation Fact) ready for Power BI dashboards.

🔄

Scheduled Refresh

Supports hourly, daily, and weekly automated data collection with full refresh history logging.

🔐

Secure & Private

All data stays on the seller's local machine. Credentials are never logged. OAuth 2.0 tokens are stored in a local encrypted SQLite database.

How It Works

  1. Seller authorizes the app via Shopee OAuth 2.0
  2. The tool collects order and product data via Shopee Open Platform API
  3. KPIs and product metrics are computed locally
  4. Business recommendations are generated based on configurable rules
  5. Reports are exported as JSON summaries and Power BI-ready CSV files

API Permissions Required

  • Order data — Read order list and order details for the authorized shop
  • Product data — Read product listings, pricing, and stock information
  • Shop profile — Read basic shop information

This tool only reads data. It does not create, modify, or delete any orders, products, or shop settings.

Contact
